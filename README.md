## 🚀 Instalación

Clona el repositorio:

```bash
git clone https://github.com/TU_USUARIO/roubian-dotfiles.git
cd roubian-dotfiles
```

Da permisos al instalador:

```bash
chmod +x install.sh
```

Ejecuta:

```bash
./install.sh
```

Recarga i3:

```text
Mod + Shift + R
```
